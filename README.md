# Ledger Inbox

Offline capture page for Life Ledger. This repo is a published copy of the `inbox/`
folder of the private LifeLedger repo — **edit it there, then copy the four files
here.** It holds no secrets: the endpoint URL and token are typed into the page on
the phone and stored only in that device's localStorage.

Bump `CACHE_VERSION` in `sw.js` on every change, or installed phones keep the old page.
